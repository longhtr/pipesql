# Independent reference implementations

These Python modules construct or interpret data independently of Rust production
code. They use only the standard library and require assertions enabled.

| Module | Responsibility |
| --- | --- |
| `single_table.py` | Format-1 encoder and corruption checks for rejected single-table fixtures. |
| `attempt_reuse.py` | Format-2 encoder and corruption checks; also supplies primitives to the current legacy snapshot fixture encoder. |
| `multi_table.py` | Format-3 encoder and corruption checks; supplies the retired candidate-format fixture encoder. |
| `q1_compare.py` | Strict independent Q1 CSV / typed CLI comparison, including raw DOUBLE bits and row counts. |

Run `python3 tools/check-fixtures.py` to compare generated bytes with committed
fixtures. The layout modules can also run their own assertions and report hashes;
they do not write files. Run `python3 tools/test-q1-compare.py` for the comparator's
negative controls. To compare explicit captured outputs, use
`python3 tools/oracles/q1_compare.py ORACLE PRODUCTION` or
`python3 tools/oracles/q1_compare.py --all-groups PRODUCTION`.

The encoders retain distinct format discriminators. Their shared-looking checks
must not be replaced by imports from production codecs.
